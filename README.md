# TODO App

Node.js/Expressを利用して作成した、ログイン機能付きのTODO管理Webアプリです。

## 主な機能
- ユーザー登録
- ログイン/ログアウト
- 未ログイン時のアクセス制限
- TODOの追加
- TODOの一覧表示
- キーワードによるTODOの絞り込み
- TODOの更新
- TODOの削除
- SQLiteを使用したデータ保存
- ユーザーごとのTODO管理

## 使用技術
- HTML
- CSS
- JavaScript
- Node.js
- Express
- SQLite

## 工夫した点

ログインしていない状態ではTODO画面を利用できないようにし、ログイン後にTODOを管理できるようにしました。
ログインしたユーザーごとにTODOを分け、他のユーザーのTODOが表示されないようにしました。
また、TODOの追加・表示・検索・更新・削除といった基本的なCRUD機能を実施し、データベースに保存できるようにしました。
